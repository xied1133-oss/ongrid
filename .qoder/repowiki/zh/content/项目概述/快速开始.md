## 简介
本指南面向首次接触 Ongrid 的用户，目标是在最短时间内完成完整环境的部署并体验核心功能。Ongrid 提供两种主要部署方式：
- 一键部署脚本：适合在 Linux 服务器上一键拉起全栈（含 HTTPS、内置监控、知识库等）。
- Docker Compose：适合本地开发与调试，快速启动 MySQL、Manager、Nginx、Prometheus、Grafana、Loki、Tempo、Qdrant、SearXNG 等组件。

## 环境要求与前置依赖
- 操作系统：Linux（amd64/arm64）
- 容器运行时：Docker 及 Docker Compose v2（命令为 docker compose）
- 网络：对外端口需放行（默认 HTTPS 443 或可配置的 HTTP_PORT；Edge 隧道端口 40012）
- 内存建议：≥2GB（低于建议值会给出警告）
- 可选：OpenAI API Key（用于 AI Chat；留空则不影响其他功能）

说明：
- 一键脚本会自动检测并提示安装 Docker（若未安装），并校验架构与依赖。
- 生产式安装会在宿主机创建数据目录并设置权限，便于备份与迁移。

## 一键部署（推荐）
适用场景：在阿里云 ECS 或其他 Linux 服务器上快速拉起完整 Ongrid 栈。

步骤概览
- 以 root 或 sudo 用户执行一键脚本。
- 脚本将自动下载发布包、校验完整性、预填配置、运行官方安装器并拉起服务。
- 完成后输出 Web UI、Grafana、Edge 隧道地址以及管理员初始密码提示。

关键要点
- 可通过环境变量覆盖版本、下载源、HTTP 端口、管理员邮箱/密码、OpenAI 模型等。
- 支持 CDN 优先、GitHub Release 回退的下载策略，并提供 SHA-256 校验。
- 部署后自动探测公网 IP 并打印访问入口。

示例命令（按需替换变量）
- 基础一键部署：sudo ./deploy/one-click-deploy.sh
- 指定版本与管理员邮箱：sudo ONGRID_VERSION=v0.13.4 ADMIN_EMAIL=ops@corp.com ./deploy/one-click-deploy.sh
- 启用 OpenAI：sudo OPENAI_API_KEY=sk-xxx OPENAI_MODEL=gpt-4o ./deploy/one-click-deploy.sh

注意
- 请确保服务器安全组已放行 HTTPS 端口（默认 443，可在 .env 中改为 8443 等）和 Edge 隧道端口 40012。
- 自签证书浏览器会告警，点击“高级 → 继续访问”即可。

## Docker Compose 本地开发
适用场景：在本地机器上快速启动开发环境，包含数据库、管理器、前端代理、指标与日志追踪后端等。

启动步骤
- 进入 deploy 目录：cd deploy
- 复制并编辑环境变量（如需修改端口、密钥等）：cp .env.example .env
- 启动服务：docker compose up -d
- 停止服务：docker compose down

说明
- 该 compose 定义包含 mysql、ongrid、nginx、frontier、prometheus、loki、tempo、qdrant、grafana、searxng 等服务。
- ongrid 服务通过健康检查等待 mysql 就绪后再连接。
- 开发模式默认不暴露 8080 到宿主机，仅暴露 metrics 端口 9100；HTTPS 由 nginx 提供（本地 dev 也可自行配置证书）。

常用端口
- ongrid HTTP API：容器内 8080（compose 默认不映射宿主）
- ongrid Metrics：9100
- Edge 隧道：40012
- Prometheus：9090（本地开发）
- Grafana：3000（本地开发）
- MySQL：3306（本地开发）

## 裸机安装（生产式）
适用场景：在生产服务器上以 release 包形式安装，具备 TLS、数据持久化、升级与运维能力。

步骤概览
- 下载对应架构的 tar.xz 包并解压。
- 进入解压目录，执行 sudo ./install.sh。
- 安装器将：
  - 准备 Edge 资源（二进制/依赖）并原子替换。
  - 创建并授权数据目录（MySQL、Prometheus、Loki、Tempo、Grafana、Qdrant 等）。
  - 生成自签名证书（可后续替换为正式证书）。
  - 从模板生成 .env，填充缺失的密钥与管理员信息。
  - 拷贝配置文件（nginx、prometheus、loki、tempo、grafana、searxng 等）。
  - 启动 docker compose 服务。

可选参数
- --profile monitoring：同时启动 Prometheus（compose profile）。
- --no-seed：跳过管理员引导提示。
- --force：在已有安装上重新安装（保留 .env 与数据卷）。

注意事项
- 安装器会尝试自动安装 Docker（若未安装），但需要系统包管理器可用。
- 若无法访问 get.docker.com，会回退到发行版包管理器安装。
- 安装完成后，Web UI 默认通过 HTTPS 暴露（端口可在 .env 中调整）。

## 基本配置与自定义
核心配置项（位于 .env 或 compose 环境变量）
- 端口与网络
  - ONGRID_HTTP_PORT：HTTPS 对外端口（默认 443，可改为 8443 等）
  - ONGRID_HTTP_REDIRECT_PORT：80→443 重定向端口（设为 0 可禁用）
  - ONGRID_TUNNEL_PORT：Edge 隧道端口（默认 40012）
  - ONGRID_METRICS_PORT：Metrics 端口（默认 9100）
- 数据库
  - MYSQL_ROOT_PASSWORD / MYSQL_PASSWORD：MySQL 密码（留空则由安装器生成）
  - 本地开发可使用 SQLite（仅本地实验）：设置 DB 方言与路径
- 管理员与认证
  - ONGRID_ADMIN_EMAIL / ONGRID_ADMIN_PASSWORD：首次登录管理员账号（留空则自动生成随机密码）
  - ONGRID_JWT_SECRET：JWT 签名密钥（留空自动生成）
- 公开地址与隧道
  - ONGRID_PUBLIC_URL：边缘侧上报数据的公共地址（安装器会尝试自动推断）
  - ONGRID_TUNNEL_ADDR：隧道地址（可从 PUBLIC_URL 推导）
- 集成与扩展
  - OPENAI_API_KEY / OPENAI_MODEL / OPENAI_BASE_URL：AI 聊天能力
  - ONGRID_PROM_ENABLED / URL：云侧 Prometheus 开关与地址
  - ONGRID_GRAFANA_INTERNAL_URL：内部 Grafana 地址
  - 通知渠道：Slack、飞书、钉钉、Webhook 等（可在 UI 或 .env 中启用）

自定义方法
- 本地开发：编辑 deploy/.env 或直接在 docker compose 中覆盖环境变量。
- 生产安装：编辑 install 目录下的 .env（由 .env.example 生成），再运行 install.sh。
- 升级与回滚：使用 install/upgrade.sh 与相关脚本进行版本切换与数据迁移。

## 常见问题与故障排查
- Docker 未安装或未运行
  - 现象：安装器报错缺少 docker 或 daemon 不可达。
  - 处理：按提示安装 Docker 并启动服务，或手动安装后重试。
- 端口冲突
  - 现象：HTTPS 或 Prometheus/Grafana 端口被占用。
  - 处理：修改 .env 中的 HTTP_PORT、PROM_PORT、GRAFANA_PORT 等，避免冲突。
- 无法访问 Web UI
  - 现象：浏览器无法打开 https://<IP>:<PORT>/。
  - 处理：检查防火墙/安全组是否放行对应端口；确认 nginx 容器状态与证书目录。
- 管理员无法登录
  - 现象：users 表为空或密码不正确。
  - 处理：确认 .env 中设置了管理员邮箱与密码；若为空则安装器会生成随机密码并在安装末尾提示。
- Edge 无法连接 Manager
  - 现象：边缘节点无法建立隧道。
  - 处理：确认 ONGRID_PUBLIC_URL 与 ONGRID_TUNNEL_ADDR 正确，且 40012 端口可达。
- 数据目录权限问题
  - 现象：服务启动时报 permission denied。
  - 处理：确保安装器已创建并 chown 数据目录；必要时手动修复 /var/lib/ongrid 下各子目录权限。
- 镜像拉取失败
  - 现象：docker pull 超时或失败。
  - 处理：配置国内镜像源或使用 release 包自带的镜像清单；检查网络连通性。
