- 包命名遵循 `ongrid.<bc>[.<subdomain>].v<major>` 三段式（如 `ongrid.manager.edge.v1`、`ongrid.tunnel.v1`），go_package 映射到 `github.com/singchia/ongrid/api/gen/<path>/v1;<pkg>v1`。
- 每个 RPC 都拥有独立的 Request / Response message（即使为空），保证向前兼容且避免复用导致歧义。
- ID 统一使用 `uint64`，时间字段使用 `google.protobuf.Timestamp`，令牌类字段使用 `string`。
- `org_id` 不作为用户提供的请求字段出现在消息中，而是由 `internal/pkg/auth` 中间件从 JWT claims / URL path 注入（响应中可只读回显）。
- `optional` 仅在明确存在性负载时使用，默认省略可选字段；每个 service 的所有消息集中在单个 `.proto` 文件中，不拆分。
- tunnel 协议刻意不 import manager 子域消息，而是复制必要类型（如 HostInfo、HostMetricPoint）以保持 tunnel proto 自包含与独立演进。
