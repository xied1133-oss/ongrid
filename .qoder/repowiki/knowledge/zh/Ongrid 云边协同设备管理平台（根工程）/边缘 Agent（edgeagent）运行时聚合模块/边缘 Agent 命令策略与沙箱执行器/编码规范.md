- 每个二进制通过 `addBin(&BinaryPolicy{...})` 注册，对同一 Bin 多次调用时后者优先覆盖，便于先注册基础规则再追加 DeniedArgs 或更细粒度匹配器。
- 读写行为通过 `ReadOnlyMatchers` 与 `WriteMatchers` 的 `ArgMatcher` 表达，匹配顺序固定为 DeniedArgs → WriteMatchers → ReadOnlyMatchers → class 默认，mixed/network 类默认保守拒绝。
- ArgMatcher 统一使用三种子规则：`AnyFlag`（任意位置 flag 命中）、`Subcmd`（argv[1] 精确匹配）、`SubcmdPath`（多 token 前缀匹配），空匹配器作为 catch-all 用于「其余一律视为写」场景。
- 策略与沙箱分离：`Policy.Decide` 只做规则判定不碰文件系统/网络，`Sandbox.Decide` 在此基础上追加 PathValidator 与 NetworkHostAllowlist 校验，便于独立做 dry-run 审计。
- YAML 覆盖采用「非 nil 才替换」的增量合并语义：`NetworkHostAllowlist`、`PathAllowlist`、`TimeoutSeconds`、`MaxArgvLength` 仅在 YAML 显式设置时覆盖 base，避免误清空默认白名单。
- 所有外部可执行入口均通过 `exec.CommandContext` + `context.WithTimeout` 运行，并使用 `SysProcAttr.Setpgid` 将管道内进程归入同一进程组以便超时统一终止。
