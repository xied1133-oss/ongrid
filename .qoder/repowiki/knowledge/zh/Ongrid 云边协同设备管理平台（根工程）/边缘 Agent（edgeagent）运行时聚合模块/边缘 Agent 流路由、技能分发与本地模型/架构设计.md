本模块由三个相互独立、职责清晰的子包组成：
- `streamrouter`：维护单个 `AcceptStream` 循环（`acceptLoop`），从 `Acceptor` 接口拉取 `tunnel.StreamConn`，通过解析连接元数据中的 JSON `kind` 字段匹配到注册的 `Handler` map，未命中则回退到 `fallback`；每个 handler 在独立 goroutine 中运行并带 panic 恢复与日志记录。
- `skill`：作为 edge 侧 `execute_skill` 的入口，`Dispatch` 将请求体反序列化为 `{key, params}`，调用共享 skill 注册表 `skill.Get(key)` 获取 `Executor` 并执行，错误统一封装进 `{result, error}` 响应体，使上层 RPC 不失败而仅携带业务错误，便于审计追踪。
- `model`：存放边端本地类型（`HostMetric`、`ProcessInfo`），刻意与 manager 侧同构但独立复制，以维持 BC 边界，避免 edge 直接依赖 manager 包。
依赖方向单向：`skill` 依赖外部 `internal/skill` 注册表，`streamrouter` 依赖 `internal/pkg/tunnel`，三者之间无互相引用，便于各自独立演进。
