- 对外暴露的最小接口：`streamrouter` 通过 `Acceptor` 接口解耦底层 tunnel 实现，`Register` 函数启动后台协程接管生命周期。
- handler 异常隔离：所有被分发的 stream handler 均在 goroutine 中以 defer recover 包裹，panic 信息连同堆栈经 slog 记录后不传播给 acceptLoop。
- RPC 错误语义下沉：`skill.Dispatch` 不向上层返回 transport 错误，而是把 executor 错误编码进响应体的 `error` 字段，保持 RPC 成功状态以便审计。
- 跨进程边界类型复制：edge 与 manager 之间的协议结构体（如 `HostMetric`）在 edge 侧重新声明，避免 edge 反向依赖 manager 包，维持单向依赖。
