本模块由三个并列的 handler 包组成，均围绕 `internal/pkg/tunnel` 提供的 RPC/Stream 抽象实现，按职责划分：
- `operator`：注册 `MethodOperatorExec`（一次性 exec）与 `MethodOperatorExecStart`（长连接 PTY 流式执行），通过白名单命令路由（list_netns/ping/dig/tcp/http）+ 参数校验 + `netns exec` 沙箱限制实际执行的二进制；PTY 输出经 base64 编码的 JSON 事件流回推，支持 runID 异步推送。
- `service`：注册 cloud→edge 的采集接口（get_host_load、get_process_list），通过可选的 `biz.Collector` 注入真实实现或 stub，保持向后兼容。
- `webshell`：以 `Acceptor` 接口接收 manager 发起的 Stream，解析 Meta 中的 target 并严格限定在白名单（127.0.0.1:22、localhost:22），仅做双向 `io.Copy` 转发，SSH/PTY/审计逻辑全部外置到 manager。
依赖方向单向：三者都只依赖 `tunnel` 协议层与各自业务域（operator 依赖 `os/exec`/`creack/pty`，service 依赖 `biz.Collector`，webshell 依赖标准库 net），彼此之间无耦合。
