- 每个子包对外暴露 `Register(client, log)` 入口，内部将 handler 通过 `client.RegisterHandler(...)` 注册到 tunnel 协议方法上。
- 对来自远端的输入统一先做白名单/格式校验再构造系统调用或网络请求，失败时返回结构化错误响应而非直接 panic。
- 流式处理采用 goroutine + WaitGroup 模式：PTY/stdout 读取与命令等待并行，结束时统一发送 `done` 事件并清理资源。
- 日志统一使用 `log/slog`，并通过 `slog.String/Int/Any` 等字段记录关键上下文（command、exit_code、target 等）。
- 可插拔实现通过 interface（如 `biz.Collector`、`Acceptor`）注入，并提供 nil 时的 stub 行为以保证向后兼容。
