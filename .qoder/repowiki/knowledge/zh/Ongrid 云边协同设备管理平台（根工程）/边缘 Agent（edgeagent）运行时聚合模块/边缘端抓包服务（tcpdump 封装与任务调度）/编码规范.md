- 使用 Go build tag（`//go:build linux` / `//go:build !linux`）将平台相关实现拆分为独立文件，非 Linux 平台提供同名类型与返回固定错误的占位实现。
- 对外部可执行命令（tcpdump）的调用统一通过 `exec.Command` + `StdoutPipe`/`StdinPipe` 组合，并将 stderr 收集到 `bytes.Buffer` 以便错误信息中附带原始输出。
- 所有用户输入在入口处经 `normalizeRequest` 集中校验与默认值填充，采用白名单方式限制 capture_id、interface、network_namespace、BPF filter 等字段的取值范围。
- 长生命周期状态（`Service.tasks`、`Result.LivePreview`）通过 `sync.RWMutex` 保护，并在每次访问后通过 `cloneTask` 或切片拷贝返回副本，避免外部修改内部状态。
- 任务状态机使用字符串常量（`queued`/`running`/`succeeded`/`failed`/`cancelled`）表示，并通过 `GetAfterCancel`/`updateProgress` 等方法在锁内安全更新。
- 错误消息统一以 `packet capture:` 前缀开头，便于在日志中快速过滤定位来源。
