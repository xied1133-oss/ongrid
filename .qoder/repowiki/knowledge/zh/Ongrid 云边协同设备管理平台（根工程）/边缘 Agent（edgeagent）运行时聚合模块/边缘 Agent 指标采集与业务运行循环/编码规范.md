- 对外能力通过接口解耦：collector 包定义 `Collector` 接口，biz 包仅依赖该接口而非具体实现，便于在 embedded 与 scrape 之间切换。
- 每个采集 tick 同时产出 legacy fast path（`HostMetricPoint`）和 open-set rich path（`[]PromSample`），由 `pushOne` 分别走 `push_host_metrics` 与 `push_prom_samples` 两条 wire 方法。
- 并发任务统一使用 `errgroup.WithContext` 管理 goroutine 生命周期，并在 context 取消时优雅退出，错误仅记录不中断其他 target。
- RPC 请求参数统一通过 `jsonDecode`/`jsonEncode` 包装进行编解码，失败时返回带上下文的错误信息。
- 可选能力通过接口断言启用：如 `NetworkDiscoveryCollector` 仅在实现该接口且配置开启时才启动 discovery loop。
- 外部依赖调用均带超时 context（如 10s/15s），避免阻塞导致整个 agent 卡死。
