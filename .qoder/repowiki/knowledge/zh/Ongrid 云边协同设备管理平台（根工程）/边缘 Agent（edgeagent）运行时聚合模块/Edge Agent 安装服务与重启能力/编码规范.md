- 跨平台差异通过 Go build tag 分文件实现：`*_windows.go` 提供真实逻辑，`install_other.go` 返回 `ErrUnsupportedPlatform`，接口定义放在无 build tag 的公共文件中。
- 外部系统交互统一通过小接口抽象（`SecretStore`/`ServiceController`/`EnvWriter`），调用方只依赖接口而非具体实现，便于测试与跨平台复用。
- 敏感操作采用原子替换模式：先写临时文件 → apply ACL → rename 覆盖 → round-trip 验证，失败时回滚到调用前状态。
- 服务控制命令错误处理区分预期与非预期错误：如 `Stop()` 对 `sc.exe` 的 1060/1062 退出码静默忽略，其他错误包装后上抛。
- 边缘侧 mutating 操作在 tunnel 层做二次白名单校验：请求参数经 `canonicalUnit` 规范化后与预计算的 `allowed` map 比对，空列表视为不安全配置。
