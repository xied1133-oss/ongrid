以 `src/main.tsx` 为唯一入口，在首次渲染前通过 `store/theme` 与 `store/mode` 恢复主题/强调色并设置 `document.documentElement.lang`，随后用 `react-router-dom` 的 `BrowserRouter` 挂载 `App` 完成路由装配；各业务页面（agents、clusters、edges、flows、knowledge、monitor、observability、alerts、settings 等）均遵循同一契约：通过 `src/api/*` 中的领域化 HTTP 客户端调用后端，使用 `src/store/*` 中的 Zustand store 读写跨组件状态，复用 `src/components/ui` 与 `src/lib` 提供的通用 UI 原语与工具函数；E2E 测试位于 `e2e/`，单元测试位于 `src/**/*.test.*`，由 `playwright.config.ts` 与 `vitest.config.ts` 分别驱动。构建产物由 `vite.config.ts` 输出到 `dist/`，由 Nginx/Apache 等静态服务器托管。
