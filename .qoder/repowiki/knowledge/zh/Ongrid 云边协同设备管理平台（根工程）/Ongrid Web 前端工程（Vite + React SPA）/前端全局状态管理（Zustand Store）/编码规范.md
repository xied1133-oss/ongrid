- 每个 store 文件定义 TypeScript 类型（State/Session/Me 等）并通过 `create<State>()` 导出同名 useXxx Hook，将 state 与 actions 一并暴露。
- 需要跨刷新保留的状态统一使用 `persist` + `createJSONStorage(() => localStorage)`，并以 `ongrid.*` 命名空间区分不同 store 的 localStorage key。
- 对外暴露的 store 通常同时导出纯函数形式的 getter/invalidate（如 `getToken`、`invalidateChatSessions`），以便非 React 上下文也能读取或触发刷新。
- 异步数据加载在 store action 内设置 loading 标志，成功时写入数据、失败时保持 loading=false，错误信息根据场景选择静默或上报。
- 跨 store 依赖通过 `useXxx.getState()` 读取其他 store 的当前值（如 incidentBadge 读 auth.token、me 读 auth.role），而非通过 props 传递。
- 全局偏好类功能（主题）优先使用原生 API（localStorage + matchMedia + CustomEvent）而非 Zustand，以支持首屏同步与跨框架通信。
