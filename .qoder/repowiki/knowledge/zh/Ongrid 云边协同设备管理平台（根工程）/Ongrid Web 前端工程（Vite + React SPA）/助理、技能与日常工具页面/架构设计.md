本模块由三个独立的 React 页面组件构成，均位于 `web/src/pages/` 下，作为路由级入口向外暴露默认导出：
- `Agents.tsx`：助理（Agent）清单页，通过 `@/api/agents` 的 `listAgents/createUserAgent/updateUserAgent/deleteAgent` 完成内置/预置/用户自定义助理的只读展示与 CRUD；通过 `@/api/skills` 与 `@/api/mcp` 并行拉取可用工具列表填充表单多选；通过 `createSession(agent_id)` 跳转到 `/chat/:id` 启动会话。
- `DailyTools.tsx`：日常工具台，聚合 ping/dns/tcp/http/tcpdump 五种工具，使用 `@/api/operatorRuns` 的 `createOperatorRun/streamOperatorRunEvents/cancelOperatorRun` 执行远程探针并以事件流增量更新本地 `ToolRun` 状态；抓包路径走 `@/api/packetCaptures` 的 session + member 模型，配合 `setInterval` 轮询 `refreshPacketCaptureSession/getPacketCapture` 并合并到 `CaptureQuickRun`；运行历史通过 `localStorage` 持久化并在刷新后恢复 running 任务。
- `Skills.tsx`：技能目录页，同时拉取 `@/api/skills` 与 `@/api/flows`（MCP flow tools），用 `toolGroupKey/groupTag/groupTitle/orderedGroupKeys` 统一分组为内置技能、MCP server、扩展包三类，并通过 `lazy(() => import('@/pages/settings/Marketplace'))` 按需加载管理员可见的“扩展”安装标签页。

依赖方向单向向下：页面 → `@/api/*` 数据层 → 后端 REST/SSE；UI 复用 `@/components/ui`（Button/Card/PageHeader/EmptyState）、`@/components/Modal`、`@/i18n/locale` 的 `useI18n` 做国际化，不互相引用，彼此解耦。
