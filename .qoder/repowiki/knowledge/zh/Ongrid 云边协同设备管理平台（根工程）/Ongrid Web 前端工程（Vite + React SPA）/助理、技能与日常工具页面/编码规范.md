- 所有用户可见文案通过 `useI18n().tr(zh, en)` 调用，中英文成对传入，禁止硬编码字符串。
- 异步副作用统一采用 `try/catch` 捕获 `ApiError` 并写入局部 `err` state 展示，成功时清空错误再刷新数据。
- 列表类页面（Agents、Skills）遵循「loading / refreshing / error / empty」四态渲染模式，并通过 `useMemo` 在客户端做搜索与排序过滤。
- 弹窗式子功能（编辑、删除确认、详情查看）以独立函数组件形式定义在本文件内，通过 props 回调与父组件状态联动，不使用全局 store。
- 对外部 API 的错误信息统一通过 `e instanceof ApiError ? e.message : (e as Error).message` 归一化后再展示。
- 长耗时或可选能力采用 `lazy` + `Suspense` 懒加载（如 Skills 的安装标签页），避免阻塞首屏。
