- UI 原子组件通过 `forwardRef` + `className` 透传，并使用 `cn()` 合并默认样式与调用方传入的类名，保证视觉一致性。
- 多语言文案统一通过 `useI18n().tr('中文', 'English')` 或 `trInline` 获取，避免硬编码字符串。
- 侧边栏导航项以声明式数组（`SidebarSectionItem` / `CollapsibleSection.items`）配置，icon、label、to、badge 等元数据与渲染解耦。
- 用户偏好（如侧边栏分组展开/隐藏）持久化到 localStorage，并以 `sidebar.section.<key>` 命名空间隔离不同区域的状态。
- 弹窗/下拉菜单统一通过 `createPortal` 挂载到 `document.body`，并配合 `mousedown`/`keydown(Escape)` 监听实现点击外部关闭。
- 品牌徽标组件遵循统一 props 接口 `{ size, className, style }`，并通过 `brandFromModel` / `brandFromProvider` 分派到具体 SVG 实现。
