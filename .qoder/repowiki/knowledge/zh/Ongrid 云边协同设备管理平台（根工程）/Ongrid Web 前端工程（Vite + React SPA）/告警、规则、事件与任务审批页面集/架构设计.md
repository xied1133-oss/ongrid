本模块由五个独立的 React 页面文件组成，均位于 `web/src/pages/`，作为路由级入口向外暴露默认组件：
- `Alerts.tsx`：告警列表页，通过 `usePoll` 每 30 秒轮询 `listIncidents`，支持按状态/严重度筛选、分页、Ack/Resolve 操作，并通过 `useIncidentBadge` store 同步侧边栏未确认计数；目标设备名通过 `listEdges` 本地缓存映射。
- `AlertRules.tsx`：告警规则管理页，含规则列表、内置/自定义区分、基于 `RULE_KINDS`/`RULE_PRESETS` 的创建/编辑 Modal、`previewRule` 预览曲线（recharts），以及运行时 cadence 展示。
- `IncidentDetail.tsx`：单条 incident 详情页，并行拉取 incident + events，使用双层轮询（正常 30s + AI 初查阶段 5s × 90s 窗口），集成根因分析报告面板、AI 初查面板、Agent 时间线、Grafana/Loki/Tempo 跳转及 Chat 深入诊断会话。
- `Tasks.tsx`：统一的任务入口，根据路由参数在 `TaskList` 与 `TaskDetail` 间切换，复用 `ReportCards` 展示产物，并内嵌 `ScheduleForm`/`OneoffForm` 管理定时/一次性任务。
- `Approvals.tsx`：待确认审批收件箱，按 `pending/approved/executed/rejected/failed` 过滤，调用 `approveApproval`/`rejectApproval` 完成危险操作放行。

依赖方向单向向下：页面 → `@/api/*`（alerts/tasks/reports/approvals）、`@/store/*`（权限、badge）、`@/components/*`（Modal、ui）、`@/lib/*`（格式化、轮询、drilldown）。页面之间仅通过路由链接（如 `/alerts/rules`、`/alerts/incidents/:id`、`/tasks/:id`）松耦合协作，无跨文件直接 import。
