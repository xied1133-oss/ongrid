- 所有用户可见文案统一通过 `useI18n().tr(zh, en)` 或 `trInline` 获取，禁止硬编码中英文字符串。
- 错误提示采用统一的红色边框卡片样式（`border border-red-500/20 bg-red-500/10 text-red-300`）并以 `role="alert"` 标注。
- 异步数据加载使用 `useState` 维护 loading/error/items 三元态，并在 try/catch 中捕获 `ApiError` 或通用 Error 设置错误消息。
- 周期性刷新统一通过 `usePoll(refresh, intervalMs)` 封装，避免在多个 useEffect 中重复写定时器。
- 模态框统一使用 `@/components/Modal` 组件，表单提交前进行本地校验（如端口范围、JSON 解析），失败时设置 `err` 状态而非抛错。
- 路由状态通过 URL search params（如 `?roles=`、`?tab=`、`?view=`）同步到浏览器地址栏，便于分享与回退。
