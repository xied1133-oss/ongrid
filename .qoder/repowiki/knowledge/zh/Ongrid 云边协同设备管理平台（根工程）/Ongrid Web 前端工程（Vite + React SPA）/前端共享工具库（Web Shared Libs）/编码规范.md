- 工具函数以纯函数形式导出，避免在 lib 层维护全局可变状态（仅 drilldown.ts 对 grafana root URL 做模块级 TTL 缓存并通过 invalidateGrafanaRootCache 显式失效）。
- 所有面向用户的字符串均通过 trInline 或直接传入 zh/en 双语键，保证中英文切换一致。
- 对空值/null/undefined 的统一处理：format.ts 中返回 '—' 占位符，其他工具函数也显式守卫空输入后短路返回。
- 跨组件通信优先使用 window 自定义事件（events.ts 的 onDevicesChanged/notifyDevicesChanged），而非引入完整 zustand store。
- PromQL 操作采用正则替换而非引入完整解析器，保持单文件 <1KB 且只覆盖 splice matcher 的最小场景。
- React Hook 通过 useRef 包裹回调并在 useEffect 中根据 enabled/intervalMs 重新挂载，遵循稳定引用约定以避免重复计时器。
