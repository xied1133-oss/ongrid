本模块是 web/src/lib 下的扁平工具包，每个文件暴露一组无副作用的纯函数或 React Hook，被 pages、store、components 直接 import 使用，不互相依赖形成内部层级。核心职责按文件划分：drilldown.ts 负责构造 Grafana Explore/仪表盘 deep-link 并处理 nginx auth_request ticket cookie 与弹窗策略；promql.ts 通过正则向 PromQL 表达式注入 device_id 匹配器；frontmatter.ts 提供极简 YAML frontmatter 剥离；format.ts 基于 @/i18n/locale 输出相对时间、字节、数字等本地化格式；usePoll.ts 提供可见性感知的定时轮询 Hook；events.ts 封装 window 自定义事件用于跨组件广播（如设备变更）；toolSkill.ts 集中定义工具分组规则与排序；configDraftConfirmation.ts 生成/识别配置草案确认消息；其余 cn.ts、grafanaVars.ts、icon.ts、keyboard.ts、paramDescEn.ts、rule_presets.ts 提供语言常量、Grafana 变量映射、图标名、IME 输入法检测、参数描述、规则预设等零散能力。模块对外仅通过 ES module export 暴露 API，不持有全局状态（除 drilldown.ts 内对 grafana root URL 的 60s TTL 缓存）。
