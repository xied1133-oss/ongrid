本模块由四个独立的 React 页面组件构成，均位于 `web/src/pages/` 下，作为 SPA 路由下的顶层视图：
- `Knowledge.tsx`：知识库主入口，通过 `@/api/knowledge` 的 `listDocs/searchKnowledge/syncVault/uploadDoc/moveDoc` 等接口，将扁平路径字符串解析为左右两栏布局——左侧按 source_type 拆分为“组织”和“内置”两个独立文件夹树（`ScopeTreeSection` + `FolderNode`），右侧展示文档卡片并支持拖拽移动（ADR-029）、编辑/删除弹窗；Markdown 正文经 `react-markdown` + `remark-gfm` 渲染，YAML frontmatter 用 `splitFrontmatter` 剥离后单独展示。
- `KnowledgeRepos.tsx`：代码仓库管理页，调用 `listRepos/createRepo/syncRepo/deleteRepo` 及 SSH 凭证相关 API，维护 `SSHIdentitiesCard` 与 `AddSSHIdentityModal`（generate/paste 双模式），并通过本地 `gitErrorHint` 把后端 git 原始错误翻译为多语言提示。
- `ReportDetail.tsx`：单条报告的详情/分享/导出页，使用 `usePoll` 在 `pending/generating` 状态下轮询状态，内容通过 `ReportContentView` 渲染，并展示 delivery 投递状态面板。
- `Pages.tsx`：产物总览页，以 `?tab=pages|reports|packets` 切换三个子视图；`pages` tab 通过 `fetchPageHTML` 拉取 HTML 并用 `sandbox=""` 的 iframe srcdoc 安全缩略图/预览；`reports` tab 复用共享 `ReportCards` 组件；`packets` tab 实现抓包会话列表、逐包过滤、协议树与十六进制视图。
依赖方向单向向下：页面 → `@/api/*` 客户端 → 后端 REST；UI 样式统一走 `@/components/ui`（Button/Card/PageHeader/EmptyState）和 Tailwind，国际化通过 `useI18n().tr(zh, en)` 成对传入。
