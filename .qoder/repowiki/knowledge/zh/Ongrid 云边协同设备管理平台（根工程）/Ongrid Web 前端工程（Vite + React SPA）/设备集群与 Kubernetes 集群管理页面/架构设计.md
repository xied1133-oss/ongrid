模块以两个顶级页面组件为入口：`Clusters.tsx` 渲染设备集群列表与 `DeviceClusterDetailPage`，`Kubernetes.tsx` 渲染 K8s 集群列表与 `KubernetesClusterDetailPage`。每个页面通过 `@/api/*` 直接调用后端接口（topology、devices、edges、kubernetes），并在本地用 `useState`/`useMemo`/`useCallback` 维护加载态、错误态与筛选状态。

- 子目录按职责拆分：`clusters/` 聚焦设备集群的数据建模与升级编排（`model.ts` 聚合 TopologyNode/Device/Relation/EnrollmentProfile 生成 `DeviceClusterSummary`；`upgrade.ts` 计算升级目标、分组与分批；`ClusterBatchUpgradeModal`、`ClusterEnrollmentModal`、`ClusterManagementModals`、`ClusterUpgradeHistory` 为弹窗与历史视图）。
- `kubernetes/` 聚焦 K8s 侧能力：`model.ts` 定义常量（POLL_INTERVAL_MS、RESOURCE_PAGE_SIZE）、同步健康判断（`clusterSyncRisk`、`syncHealthText`）、命令生成（`kubernetesUpgradeCommand`、`kubernetesUninstallCommand`）；`edgeAttachments.ts` 分页拉取并缓存 Edge 与 K8s 控制器/节点的关联关系，供设备集群页区分 K8s 托管 Edge；`KubernetesLifecycleModals.tsx` 提供创建、删除、升级/卸载命令弹窗。
- 依赖方向单向：页面 → 本目录 model/upgrade/edgeAttachments → `@/api/*` 与共享 UI/i18n/store，页面之间不互相引用，仅通过路由 `/clusters/:id` 与 `/kubernetes/:id` 导航。
