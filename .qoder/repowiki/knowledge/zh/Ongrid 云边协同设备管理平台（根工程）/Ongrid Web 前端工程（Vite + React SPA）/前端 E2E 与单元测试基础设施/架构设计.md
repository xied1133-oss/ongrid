模块分为两层：
- `web/e2e/`：Playwright 端到端测试集。`auth.setup.ts` 作为 setup 用例通过 `helpers.login` 完成管理员登录并持久化 `.auth/admin.json` 供后续 spec 复用；`live-navigation.spec.ts` 直接访问真实后端验证各路由渲染与主题/语言切换；`mocked-workflows.spec.ts` 与 `packet-viewer-responsive.spec.ts` 使用 `page.route` 拦截 `/api/v1/**` 返回固定 JSON，实现无副作用的确定性 UI 行为验证。
- `web/src/test/`：Vitest 单测环境。`setup.ts` 在 `beforeAll` 启动 MSW server（`onUnhandledRequest: 'error'`），并在 `afterEach` 重置处理器、`afterAll` 关闭；同时为 Node 22+ 实验性 localStorage 提供内存 polyfill，避免 `useI18n()` 在 jsdom 中崩溃；`msw-server.ts` 暴露空 server，具体 handler 由单个 `*.test.tsx` 通过 `server.use(...)` 注册，保证 fixture 与断言一一对应；`fixtures/marketplace.ts` 集中定义与后端 wire shape 一致的 mock 数据。
依赖方向：spec → helpers/auth.setup → 被测前端应用；单测 → msw-server → 被测组件，二者均不直接依赖业务 API 实现。
