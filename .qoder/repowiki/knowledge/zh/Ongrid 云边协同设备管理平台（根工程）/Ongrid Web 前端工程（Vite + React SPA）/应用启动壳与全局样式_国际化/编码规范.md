- 页面组件一律通过 `React.lazy(() => import('@/pages/...'))` 按需加载，避免首屏打包体积膨胀。
- 路由守卫以函数式组件形式封装（`RequireAuth`、`PublicOnly`），基于 `useAuth().token` 配合 `Navigate` 完成鉴权跳转。
- 对已废弃或迁移的 URL 路径统一使用 `<Route path="旧路径" element={<Navigate to="新路径" replace />} />` 进行重定向，保留书签兼容性。
- 主题通过 `:root.dark` / `:root.light` 下的 CSS 自定义属性（--bg/--card/--text 等）表达，业务组件使用 Tailwind 工具类，浅色主题通过高特异性 `html.light .xxx` 规则覆盖默认 zinc 值。
- 国际化文案以 `tr('中文', 'English')` 内联双语形式书写，语言切换通过 `window.dispatchEvent(new CustomEvent)` 广播，组件侧用 `useI18n()` hook 订阅并重渲染。
- 首次渲染前在 `main.tsx` 中同步执行主题/强调色/语言初始化，确保首屏不出现闪烁。
