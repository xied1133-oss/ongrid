- 敏感字段（token/password/api_key/app_secret）默认以 password 输入框渲染，通过独立的 reveal 开关调用后端 `/reveal` 接口获取明文，避免服务端泄露密文。
- 表单采用 server/draft 双状态 + 键集合（如 PROM_KEYS、GRAFANA_KEYS）计算 dirty，仅对发生变化的字段调用 setSetting/save，保存成功后刷新 server 并重置 savedOk。
- 所有异步操作包裹 try/catch，将 `ApiError` 的 message 提取为字符串展示，loading/saving/busy 状态用布尔或 discriminated union（idle/testing/ok/error）表示。
- 用户可见文案一律通过 `useI18n().tr(zh, en)` 进行中英双语化，禁止硬编码中英文字符串。
- 可复用的基础输入控件封装为局部 Field/PromField 组件，统一 label/hint/inputClass 样式，保证各页面输入框视觉一致。
- 危险操作（卸载包、删除渠道）先弹 Modal 二次确认，再执行 API 调用并在成功/失败后刷新列表或显示 toast。
