三个独立的 React 页面组件，分别挂载在 /settings/llm、/settings/agent、/settings/secrets 路由下，由 SettingsLayout 统一做管理员鉴权。
- LLM.tsx：以 `LLM_PROVIDERS` 元数据驱动多 Provider 卡片渲染，每个卡片维护 server/draft 双份状态并通过 `listSettings('llm')` + `revealSetting` 拉取后端系统设置；保存走 `saveLLMConfiguration`，测试走 `testLLMConfiguration`，结果通过带 signature/probeVersion 的 union state 展示成功或错误码映射。
- Agent.tsx：通过 `CATEGORY='agent'` 下的 `write_enabled`、`llm_timeout_seconds`、`output_locale` 三个 key 调用通用 `setSetting` API 进行开关/数值/枚举式配置，采用乐观更新并在失败时回滚。
- Secrets.tsx：通过 `@/api/secrets` 的 `listSecrets`/`createSecret`/`deleteSecret`/`listCredentialTypes` 管理凭据，按后端返回的 `CredType` 动态渲染字段表单（typed vs custom），值仅写不读并以 AES 加密落库。
依赖方向单向指向 `@/api/settings`、`@/api/secrets`、`@/components/ui`、`@/i18n/locale`，页面之间无相互引用，彼此独立。
