三个并列的 React 页面组件，均位于 `web/src/pages/settings/` 下，作为路由级设置子页面：
- `Users.tsx`：仅 admin 可见的用户管理页，通过 `useMe()` 判断权限，非 admin 直接渲染 EmptyState；集中管理用户列表、创建/编辑/重置密码/删除等弹窗状态，并通过 `@/api/users` 调用后端。
- `Orgs.tsx`：任意登录用户可见的组织与成员管理页，采用左右双栏布局——左侧为带搜索和层级缩进的组织树（基于 `parent_id` 计算 depth），右侧为选中组织的成员表（角色下拉 + 移除），并复用 `@/api/users` 获取用户列表以添加成员。
- `Preferences.tsx`：纯前端偏好页，通过 Zustand store `@/store/theme` 与 `@/store/mode` 读写 accent、theme mode、locale，无网络请求。

依赖方向单向向下：页面 → `@/api/*`（HTTP 客户端）、`@/components/ui`（Button/Card/Modal/PageHeader/EmptyState/Chip）、`@/store/*`（me、theme、mode）、`@/i18n/locale`（tr）、`@/lib/cn`（className 合并）。所有交互通过本地 state + 异步回调更新乐观 UI，错误统一经 `errMsg` 转为字符串后在行内或 toast 中展示。
