- 所有用户可见文案通过 `tr('中文', 'English')` 包裹，静态短文案使用 `trInline` 避免闭包开销。
- 异步操作统一采用 try/catch + `errMsg(e)` 归一化错误消息，并在成功时通过本地 toast 反馈结果。
- 表单类弹窗（Create/Edit/Reset/AddMember 等）遵循相同结构：open 控制显隐、target/id 传入目标对象、busy 防重复提交、err 显示错误、onSaved/onCreated/onDone 回调更新父组件状态。
- 表格行操作优先使用 kebab 菜单（`RowActionsMenu`）收纳次要动作，将高频操作（如编辑）保留为行内按钮以减少视觉噪音。
- 对当前用户的自我保护：禁止对自己执行删除、改角色、停用等操作，通过 `isSelf = u.id === meId` 在前端禁用对应菜单项。
- 组织树通过 `depthOf` / `flattenOrgTree` / `descendantIDs` 等纯函数在内存中计算层级与循环保护，不依赖后端返回排序。
