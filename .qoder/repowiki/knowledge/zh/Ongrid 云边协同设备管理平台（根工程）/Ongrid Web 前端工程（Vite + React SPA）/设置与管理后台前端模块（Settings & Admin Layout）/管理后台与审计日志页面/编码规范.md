- 布局组件通过 `usePermissions()` 读取 `isAdmin`，在渲染主体前短路返回带 Shield 图标的 EmptyState，实现路由级 RBAC 门控。
- 左侧 rail 以数据驱动方式声明（RailItem/RailItems 数组），每项包含 to、icon、label/hint 等元信息，再由 `RailLink` 统一渲染 NavLink。
- 所有用户可见文案通过 `tr(zh, en)` 或 `useI18n().tr` 进行双语处理，键名同时传入中文与英文。
- 子路由通过 `<Suspense fallback={<Loading.../>}> <Outlet /> </Suspense>` 包裹，使 lazy 加载仅在当前布局内部闪烁而不卸载整个 shell。
- 审计日志中的后端枚举（action/resource_type）通过集中式 `ACTION_LABELS` / `RESOURCE_LABELS` 映射表转换为可读标签，未知值回退到原始 key。
- 分页与筛选通过本地 state（filter + page）组合后调用 `listAuditLogs`，变更筛选时重置 page 为 0 并重新触发请求。
