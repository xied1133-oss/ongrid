本模块由三个 React 组件构成两层结构：
- 布局层（AdminLayout.tsx、SettingsLayout.tsx）：基于 react-router-dom 的 `NavLink` + `Outlet` 实现左侧 rail 导航 + 右侧内容区的双栏布局；通过 `usePermissions()` 获取 `isAdmin` 并在路由级做权限门控，非管理员直接渲染带 Shield 图标的 EmptyState，避免子路由继续渲染。
- 页面层（AuditLog.tsx）：挂载在 `/admin/audit`，作为 HLD-010 审计轨迹查看器，仅读且不可编辑；通过 `listAuditLogs` API 分页加载 `AuditLog`，使用本地 state 维护 filter（user_email / action / resource_type / status）、page、selected 行等状态，并通过 `formatAuditAction` / `formatAuditResource` 将后端枚举值映射为 i18n 标签。
依赖方向单向向下：布局 → 子路由 Outlet；AuditLog 仅依赖 `@/api/audit`、`@/store/me`、`@/i18n/locale`、`@/components/ui`，不反向引用布局。
