三个独立的 React 功能页面，均位于 `web/src/pages/settings/` 下，作为 Settings 子路由的叶子组件：
- `Health.tsx`：调用 `@/api/systemHealth.runSystemHealthCheck` 获取 `HealthReport`，按 `GROUP_ORDER`（core → observability → data → automation → edge → ai）分组渲染，异常项支持展开查看 message/details。
- `Upgrade.tsx`：调用 `@/api/systemUpgrade.checkSystemUpgrade` 获取 `UpgradeInfo`，根据 `comparison_supported` / `update_available` 计算状态并展示当前/最新版本、release 链接及可复制的升级命令列表。
- `Webshell.tsx`：并发拉取 `listShellSessions`、`listEdges`、`listUsers`（仅 admin），通过本地 Map 缓存用户/设备信息，实现活跃/历史过滤、全文搜索、5 秒 tick 刷新持续时间，并提供管理员强制终止会话的乐观更新。
依赖方向单向向下：页面 → `@/api/*` 客户端模块 → 后端 REST；UI 统一复用 `@/components/ui`（Card/Button/Chip/PageHeader/EmptyState）、`@/lib/cn`、`@/i18n/locale` 和 lucide-react 图标。
