模块由两个相互独立的子目录组成：
- `scripts/`：基于 bash（辅以少量 Python/jq）的发布与测试工具集，按职责分为三类——构建与发布（`publish-release-image.sh`、`publish-release-image-platform.sh`、`publish-cnb-release-attachments.sh`、`publish-helm-chart.sh`）、CNB Release 管理（`ensure-cnb-release.sh`、`sync-builtin-vault.sh`）、验证与测试（`verify-*` 与 `test-*` 系列）。脚本之间通过共享环境变量（如 `CNB_TOKEN`、`RELEASE_IMAGE_CHECK_ATTEMPTS`）和临时目录协作，依赖外部工具 `docker buildx`、`jq`、`curl`；`release-manifest-platforms.jq` 作为可复用的 jq 过滤器被多个脚本引用。
- `skills/`：以每个能力一个目录 + `SKILL.md` 的形式声明边端 Agent 可调用的工具，当前包含 `bash`（只读诊断）、`host-files`（文件读取）和 `restart-service`（mutating 重启 systemd 服务），通过 YAML front matter 描述 `metadata.requires.bins`、`edge_capabilities`、`activation.mode` 等，供 ongrid edge agent 解析并执行沙箱化命令或触发 reviewer 二审流程。
依赖方向单向向外：scripts 调用 Docker/CNB API，skills 仅描述能力契约，不直接依赖 scripts。
