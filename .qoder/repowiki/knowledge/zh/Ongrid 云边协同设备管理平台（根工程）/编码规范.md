- 所有对外 API 契约集中在 api_specs 目录的 .proto 文件，由 `make proto` 通过 buf/protoc 生成 Go 代码后供 cmd_* 与 internal_* 共同引用。
- 跨进程通信（云端↔边缘、Tunnel 消息）一律使用 api_specs 中定义的 Protocol Buffers 类型，禁止在业务层手写 JSON 结构。
- 可执行入口仅位于 cmd_ongrid 与 cmd_ongrid_edge，业务逻辑下沉到 internal_* 包，禁止在 cmd 下编写领域代码。
- 共享基础设施（配置加载、DB 连接、认证鉴权、LLM/日志/指标客户端等）统一收敛到 internal/pkg，各子模块通过 import 复用而非各自实现。
- 构建、测试、打包、发布全部经由 Makefile target，禁止在 CI 或 README 中直接调用裸 go build / docker build。
- 版本号集中维护于根级 VERSION 文件，并通过 LDFLAGS -X main.version 注入到两个二进制产物中。
