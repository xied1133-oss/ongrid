- 所有子命令统一返回 `(bool, error)`，由 main 中按顺序尝试解析并短路处理，未匹配的命令返回 false 交由下一个处理器。
- 外部可调参数一律通过 `os.Getenv` 读取并以 `parseBoolEnv` / `parseDurationEnv` / `parseIntEnv` / `envOr` 等辅助函数带默认值解析，避免硬编码分支。
- 写敏感文件（enrollment env、k8s credential、serviceaccount token）均采用「临时文件 + Sync + os.Rename」的原子替换模式，并对临时文件设置 0600 权限。
- Kubernetes 相关错误路径使用 `fmt.Errorf("...: %w", err)` 包装底层错误，便于测试断言与日志追溯。
- HTTP 请求统一构造后设置 `Authorization` 头并限制响应体大小（LimitReader），非 2xx 状态码时截断 body 一并返回错误信息。
- 可选能力（host_files、restart_service、bash、operator、webshell）采用 Register 失败即 log.Warn 继续启动的软故障策略，确保核心采集链路不受插件初始化失败影响。
