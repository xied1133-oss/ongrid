本模块为纯文档型 leaf，按主题分目录组织：`docs/adr/` 存放已归档的架构决策（ADR-029~031），`docs/design/` 存放高层设计（如 HLD-001），`docs/requirements/` 存放产品需求（PRD-001~004），`docs/rfc/` 存放技术提案（RFC-001~003），`docs/install/` 提供边缘部署说明，`docs/assets/` 存放截图与集成图标，`docs/test/` 与 `workflow-catalog.md` 描述工作流能力与 e2e 用例；`agents/` 下每个 `.md` 文件是一个独立 Agent 的提示词定义，采用 YAML frontmatter（name/description/capabilities/tools/disallowed_tools/permission_mode/max_turns/metadata）+ 正文工作流指令的结构，由 coordinator 在运行时加载并 spawn 对应 worker（如 incident-investigator、reviewer、specialist-*）。依赖方向单向：上层编排通过文件名识别 agent 角色，agent 仅声明可调用工具名，不直接引用代码。
