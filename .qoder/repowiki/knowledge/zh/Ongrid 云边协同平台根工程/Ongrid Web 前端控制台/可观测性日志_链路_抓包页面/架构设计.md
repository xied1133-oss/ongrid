本模块由五个独立的 React 页面组件组成，分别对应不同的可观测性能力：
- `Logs.tsx`：基于 Loki 的日志查询页，通过 `@/api/logs` 调用 `searchLogs`/`getLogHistogram`/`listLogFields`，使用 recharts 渲染时间直方图，支持关键词/排除词匹配、字段筛选、分页游标（nextCursor）、实时轮询（LIVE_INTERVAL_MS=5s）和 JSONL 导出。
- `Traces.tsx`：基于 Tempo 的 Trace 查询页，通过 `@/api/traces` 调用 `searchTraces`/`getTrace`，支持 TraceQL 与 service+operation facet 双模式、快捷 chip、直接 trace_id 跳转，并通过 `@/lib/drilldown` 构建 Grafana Explore URL 进行深度分析。
- `PacketCaptures.tsx`：抓包任务列表页，通过 `@/api/packetCaptures` 的 `listPacketCaptures`/`createPacketCapture`/`refreshPacketCapture` 管理任务状态（capturing/ready/failed 等），并提供新建抓包的 Modal 表单。
- `PacketCaptureSessionDetail.tsx`：多 Edge 抓包会话详情页，聚合成员 capture 与关联流（flows），支持定时刷新（2s）直至终态，并可触发 AI 分析跳转到聊天会话。
- `PacketArtifactDetail.tsx`：单个抓包产物详情页，调用 `getPacketCaptureArtifact`/`downloadPacketCapture` 并复用 `@/pages/Pages` 中的 `PacketArtifactViewer` 展示协议树与原始字节。

依赖方向单向向外：页面仅消费 `@/api/*`、`@/components/ui`、`@/i18n/locale`、`@/lib/*` 等共享层，不互相引用；跨页面导航通过 react-router-dom 的 `<Link>` 与 `useParams`/`useNavigate` 完成。所有页面统一采用 `anim-fade` + `app-header` + `PageHeader` 的布局约定，并使用 `useI18n().tr(zh, en)` 做双语文案。
