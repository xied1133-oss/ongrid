- 页面统一以 `export default function XxxPage()` 形式暴露主组件，并在顶层 `<main className="anim-fade ...">` 中包裹 `PageHeader` 与内容区。
- 所有用户可见文案通过 `useI18n().tr('中文', 'English')` 获取，避免硬编码字符串。
- 异步请求使用 `useState` 管理 loading/error 状态，错误统一通过 `ApiError` 或 `instanceof Error` 提取 message 后显示在红色边框提示块中。
- 列表数据加载使用 `useCallback` 包装并配合 `useEffect` 按依赖触发，分页通过 `page`/`pageSize` 或后端 `nextCursor` 实现。
- 需要轮询的场景（日志 live、抓包会话终态前）使用 `window.setInterval`/`setTimeout` 并在组件卸载时清理定时器。
- 对外部资源（edges、clusters、devices 等）的加载使用 `let cancelled = false` 守卫或 AbortController 信号，防止组件卸载后更新 state。
