三个并列的 React 页面组件，均挂载在 /settings 路由下，各自独立维护本地状态并通过 `@/api/*` 模块调用后端 REST API。
- `Integrations.tsx`：以四个 Card（Prometheus、Grafana、LogsIntegrationCard[Loki/Elasticsearch]、Tempo、WebSearch）组织，每个 Card 通过 `listSettings` + `revealSetting` 拉取系统设置，使用 draft/server 双状态做脏检查后批量 `setSetting`；连接测试走专用 `test*Connection` 接口，Grafana 同步走 `syncGrafana`，日志后端切换走 `saveLogBackend`，并复用 `@/lib/drilldown` 构建 Grafana Explore 深链。
- `Marketplace.tsx`：分为 InstalledList（列出已安装包、展开 Capability 摘要、CredentialBindings 绑定凭证）和 InstallCard（upload/local/tarball/git 四源），安装流程采用 POST 后弹出 ConfirmModal 二次确认并可回滚卸载；权限由 `useAuth` 的 admin role 控制。
- `Channels.tsx`：IM 渠道 CRUD，列表为表格行，编辑/删除通过 Modal 完成；provider 元信息集中在 `PROVIDER_META`，Slack 的双 token 在 UI 层拆成两个字段并在提交时 JSON 序列化到 `app_secret`，读取时通过 `revealIMAppSecret` 反解。
依赖方向单向向下：页面 → `@/api/*`（settings/logs/marketplace/imbridge/client）→ 后端；UI 样式统一来自 `@/components/ui`（Button/Card/Chip/EmptyState）和 `lucide-react` 图标。
