- 所有用户可见文本使用 `useI18n().tr('中文', 'English')` 的双参形式进行 i18n，不直接硬编码字符串。
- 数据获取采用 `useCallback` 包装的 `run(manual?)` 函数，在 `useEffect` 中自动执行一次，并通过 `Date.now()` 差值与 `MIN_MANUAL_REFRESH_MS` 节流手动刷新按钮，避免重复请求。
- API 调用统一用 try/catch 捕获 `ApiError` 并写入本地 `err` 状态，以红色边框卡片形式展示错误信息。
- 状态/分组元数据集中声明为顶层常量对象（如 `STATUS_META`、`GROUP_META`、`CHECK_LABELS`、`TERMINATED_LABELS`），通过 key 查表映射到标签、图标与颜色。
- 异步副作用统一通过 `aria-busy`、`Loader2` 旋转图标与 loading 占位 Card 表达加载中状态，完成后切换为实际内容或空态。
- 复杂列表数据通过 `useMemo` 构建 Map 缓存（userMap、edgeMap）并按业务规则排序/过滤（如 active 优先、按 started_at 倒序）。
