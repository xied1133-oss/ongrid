本模块由三个独立的 React 函数组件文件组成，分别挂载到设置路由的不同 tab：
- General.tsx：通过 `@/api/settings` 的 `listSettings`/`setSetting` 读取并写入 `platform.network_discovery_enabled` 设置项，使用本地状态管理 loading/saving/error 与 toggle 开关。
- Notifications.tsx：通过 `@/api/alerts` 的 channel CRUD（`listChannels`/`createChannel`/`updateChannel`/`deleteChannel`/`testChannel`）实现多类型通知渠道（webhook/slack/feishu/dingtalk/wecom/telegram）的增删改查与测试；以 `TYPE_CARDS` 元数据驱动卡片渲染，并按当前 locale 对 cn/intl/generic 分组排序；编辑与删除通过 `@/components/Modal` 弹窗完成，操作结果以本地 toast 反馈。
- About.tsx：仅展示静态品牌信息与动态版本号，通过 `@/api/version` 的 `getManagerVersion` 拉取 manager 版本。
三者均依赖 `@/i18n/locale` 的 `useI18n` 进行中英双语文案，UI 统一采用 Tailwind + lucide-react 图标，不共享业务逻辑，彼此独立可单独复用。
