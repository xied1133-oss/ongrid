- 所有用户可见文案通过 `useI18n().tr(zh, en)` 双参数调用，保证中英文切换时 UI 文本同步更新。
- 异步数据加载使用 `useState` 维护 loading/saving/error 三态，并在 try/catch 中捕获错误后降级为错误提示。
- 通知渠道类型以声明式 `TypeMeta[]` 数组集中定义（type/group/label/icon/hint），再按 locale 分组排序后渲染，新增渠道类型只需追加元数据。
- 表单提交前进行前端校验（名称/类型/endpoint 必填），校验失败直接设置本地 err 状态而非发起请求。
- 对外部操作（创建/更新/删除/测试）成功后通过本地 toast 反馈，toast 使用固定定位 + 颜色区分成功/失败并在超时后自动消失。
- 敏感字段（如 secret）使用 `type="password"` 输入框，并在编辑模式下支持留空保留旧值或输入 `-` 清除。
