- 所有用户可见文案统一通过 `useI18n().tr('中文', 'English')` 双参数调用，避免硬编码单语言字符串。
- 异步操作前设置 loading/saving/busy 状态并捕获 `ApiError` 显示到顶部 err 区域，请求结束后恢复状态。
- LLM 配置页对每次测试/保存分配递增的 `probeVersion` 签名，丢弃旧请求的结果，防止竞态导致的 UI 错乱。
- Provider 能力通过常量元数据数组（如 `LLM_PROVIDERS`、`PROVIDER_ORDER_*`）集中声明，再按 locale 排序渲染，新增 provider 只需追加条目。
- 敏感输入（API Key、密码字段）使用本地 `revealed` 状态切换 `type='password'`/`text`，并提供 Eye/EyeOff 切换按钮。
- Agent 配置采用乐观更新：先改前端状态再调 `setSetting`，失败时回滚并显示错误信息。
