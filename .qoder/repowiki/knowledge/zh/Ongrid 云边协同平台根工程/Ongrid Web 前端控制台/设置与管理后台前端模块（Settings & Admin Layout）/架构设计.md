本模块由两个并列的布局组件构成：SettingsLayout.tsx 负责 /settings/* 下的产品行为配置（健康、升级、集成、全局、LLM、凭证、通知、IM、Agent、偏好、关于），AdminLayout.tsx 负责 /admin/* 下的平台治理（用户、组织、审计日志），两者均使用 react-router-dom 的 NavLink + Outlet 模式，在各自路由下渲染子页面；权限控制集中在布局层，通过 usePermissions() 判断 isAdmin，非管理员直接返回 EmptyState，避免子页面重复鉴权；每个布局内部用本地 Suspense 包裹 Outlet，使懒加载的子路由切换时不卸载 rail 与 PageHeader，保持侧边栏稳定；新增子页面只需在对应 RAIL_ITEMS 数组中注册条目并实现页面组件，无需改动布局逻辑。
