- 所有用户可见文案通过 `useI18n().tr(zh, en)` 双语言包裹，禁止硬编码中英文字符串。
- 列表页采用 `useState` 维护 items/loading/refreshing/err 四态，并在 `finally` 中重置 loading/refreshing，错误统一写入 err 字段后以红色边框区块展示。
- 异步副作用统一通过 `useCallback` 包装 fetch 函数，再由 `useEffect` 触发，并用 `usePoll` 实现周期性静默刷新（如 Alerts 30s、IncidentDetail 30s+5s 快轮询）。
- 写操作按钮通过 `usePermissions()` 的 `canMutate`/`isAdmin` 控制禁用与 tooltip，只读账号无法执行 Ack/Resolve/Toggle/Delete 等操作。
- 弹窗类交互（Resolve、RuleEditor、ScheduleForm、OneoffForm、ActionDialog）统一复用 `@/components/Modal`，并以 `open` state + `onClose`/`onSaved` 回调模式组织。
- API 错误处理统一使用 `e instanceof ApiError ? e.message : (e as Error).message` 提取消息，避免裸抛错。
