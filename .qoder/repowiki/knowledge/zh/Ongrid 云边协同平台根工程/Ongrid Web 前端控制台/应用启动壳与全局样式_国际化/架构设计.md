模块由三个职责清晰的边界组成：
- 启动入口 `main.tsx`：在 `createRoot` 渲染前，先调用 `store/theme` 与 `store/mode` 的 `applyXxxOnBoot` 将持久化的主题/强调色写入 DOM，再设置 `document.documentElement.lang`，随后用 `<StrictMode>` + `<BrowserRouter>` 包裹根组件。
- 路由装配 `App.tsx`：集中声明所有页面路由，全部通过 `React.lazy(() => import(...))` 实现按路由分包；通过 `RequireAuth` / `PublicOnly` 两个高阶组件基于 `useAuth().token` 控制登录态跳转；使用嵌套 `<Route>` 组织 `/settings/*` 与 `/admin/*` 子菜单，并为历史 URL 提供大量 `Navigate to` 重定向以保持书签兼容。
- 全局样式 `styles/index.css`：基于 Tailwind (`@tailwind base/components/utilities`)，通过 `:root.dark` / `:root.light` CSS 变量定义语义设计令牌，再以高特异性选择器在 `html.light` 下把代码库中硬编码的 `zinc-*` 工具类映射到浅色主题，从而在不改动业务组件的前提下支持暗/亮双主题；同时包含 `.app-header` 毛玻璃头、Markdown 渲染样式、react-flow 控件覆盖以及 `@media print` 报告打印样式。
- 国际化 `i18n/locale.ts`：采用“内联双语字符串”模式（`tr('中文','English')`），通过 `localStorage` 持久化语言偏好，使用 `window.CustomEvent` 广播语言切换事件驱动 React 组件重渲染；自动检测策略优先依据时区（CN_TIMEZONES）再回退到 `navigator.language`，默认 zh-CN。
依赖方向单向向下：`main.tsx` → `App.tsx` → `@/pages/*`；样式与 i18n 被各层消费但不反向依赖业务组件。
