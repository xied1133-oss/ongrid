- 所有用户可见文案通过 `useI18n().tr(中文, English)` 成对传入，确保中英文同时可翻译。
- 异步副作用统一采用 `try/catch` 捕获 `ApiError` 并写入本地 `err` state，成功时刷新数据再关闭 loading。
- 列表/表单类页面遵循「加载态 → 空态 EmptyState → 数据网格」三段式渲染结构，错误信息以红色边框区块显示在顶部。
- 需要权限控制的按钮通过 `usePermissions()` / `useAuth()` 读取角色后再决定是否渲染或禁用。
- 外部不可信 HTML（Agent/工作流生成的页面）一律通过 `<iframe sandbox="">` + `srcDoc` 方式沙箱化嵌入，禁止交互事件。
- 复杂 UI 通过文件内局部函数/组件拆分（如 `ScopeTreeSection`、`FolderNode`、`RepoCreator`、`PacketAnalysisView`），每个职责单一并在同一文件中组合。
