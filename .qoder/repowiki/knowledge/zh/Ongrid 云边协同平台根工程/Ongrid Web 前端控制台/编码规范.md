- 每个业务域在 `src/pages/` 下以独立文件组织页面，并通过懒加载方式注册到路由，避免首屏体积膨胀。
- 所有后端交互集中在 `src/api/` 下按领域拆分的模块，页面不直接调用 fetch，而是通过封装好的客户端获取数据。
- 跨组件状态统一放在 `src/store/` 下的 Zustand slice 中，并通过 `useStore` Hook 订阅，禁止在页面内维护长生命周期状态。
- 可复用的 UI 片段放入 `src/components/ui`，场景化组件按子目录归类，页面仅消费而不重复实现。
- 纯函数与轻量 Hook 放入 `src/lib/`，并在文件名后附带 `.test.ts` 单元测试，保证工具逻辑可独立验证。
- 测试文件统一采用 `*.test.ts(x)` 命名，UI 组件使用 Testing Library，E2E 用例使用 Playwright 并按功能域分文件组织。
