本模块由三个独立的 React 页面组件构成，均位于 `web/src/pages/` 下，作为路由级入口：
- `Dashboard.tsx`：集群仪表盘，通过 `usePoll(REFRESH_MS=60s)` 轮询 `listDevices`、`listEdges`、`promQueryRange`（CPU/MEM/在线数）、`listSessions`、`listIncidents` 及 `/usage/today`，用 `recharts` 渲染 24h 趋势图、饼图与 Sparkline，并通过 `openMetricDrilldown` 跳转到 Prometheus 钻取页。
- `Home.tsx`：AI 助手首页，随机问候语 + 预置 Prompt 卡片，调用 `createSession` 创建会话并导航到 `/chat/:id`，同时维护 LLM 模型选择（持久化到 store 并写入后端设置）。
- `Monitor.tsx`：原生监控面板页，内置 10 个硬编码 GrafanaPanel 定义（CPU/内存/磁盘/网络/进程 Top8/负载饱和度/conntrack/TCP），通过 `injectDeviceIDFilter` 将角色/设备过滤器注入 PromQL，使用 `PanelGrid`/`UserPanelGrid`/`ProcessTopPanel` 子组件渲染，支持时间范围、自动刷新、自定义面板 CRUD 以及与 Grafana `ongrid-monitor` 仪表盘的深链互通。
依赖方向单向向外：页面 → `@/api/*` 客户端 → `@/components/*` 展示组件 → `@/lib/*`（i18n、PromQL、事件总线），不反向引用其他页面。
