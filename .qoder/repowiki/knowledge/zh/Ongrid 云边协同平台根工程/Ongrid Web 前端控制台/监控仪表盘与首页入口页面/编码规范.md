- 所有用户可见文案统一通过 `tr(zh, en)` 进行中英双语切换，禁止硬编码字符串。
- 页面级数据加载采用 `useEffect` 发起请求 + `useCallback` 封装 `loadAll`，并由 `usePoll` 定时刷新，错误状态以独立 `xxxError` state 字段承载。
- PromQL 表达式集中定义在数组或函数中（如 `buildMonitorPanels`），并通过 `injectDeviceIDFilter` 动态注入 `device_id=~"..."` 过滤器，而非在组件内拼接字符串。
- UI 布局使用 Tailwind CSS 的 grid/flex 组合（如 `grid-cols-2 md:grid-cols-3 lg:grid-cols-5`）实现响应式卡片网格，并通过 `cn(...)` 合并条件样式类。
- 可复用的小部件（KpiCard、ClusterTrend、ClusterPosture、AlertSeverityCard、NoisyRulesCard、ToolbarSelect 等）以独立函数组件形式定义在同一文件内，通过 props 接收数据与回调，保持页面主逻辑简洁。
