- 每个业务模块导出 TypeScript 类型（DTO）与同名或语义化的函数，函数内部仅调用 `request<T>(method, path, body)` 并透传泛型返回类型。
- 路径拼接时使用 `encodeURIComponent(name)` 对动态段进行编码，避免特殊字符导致路由解析错误。
- 需要无鉴权的接口通过 `{ noAuth: true }` 选项跳过 `Authorization` 头注入（如 login、refresh）。
- 类型定义旁用注释标明其镜像的后端结构（如 `mirrors backend handler/aiops::agentDTO`、`mirrors backend userAgentReq`），保持前后端契约同步。
- 对外部资源的路径支持绝对 URL（`path.startsWith('http')` 直接透传），便于对接 Grafana、Prometheus 等外部服务。
- 业务模块内可附带本地化常量（如 `BUILTIN_AGENT_I18N`）并通过 `trInline` 按当前 locale 渲染，而不修改后端数据源。
