- 所有用户可见文案通过 `useI18n().tr(zh, en)` 进行中英双语标注，禁止硬编码字符串。
- 异步副作用统一采用 `useState` 管理 loading/pending 状态，并在 try/catch/finally 中设置 error 与 pending 标志。
- API 错误统一捕获 `ApiError` 实例并按 HTTP 状态码分支处理（如 401 显示特定提示），非 ApiError 回退到通用失败文案。
- 页面内局部状态通过 `useState` + `useRef` 组合：ref 保存易失上下文（如 AbortController、滚动意图、提交标记），state 驱动重渲染。
- 列表项渲染使用稳定 key（如 `tool-card-${tool_call_id}`、`approval-${id}`），避免依赖数组索引。
- 表单字段根据后端 schema（`SkillParamDef`）动态生成控件，并通过 `serializeParams`/`initialValues` 在提交前序列化、默认值填充。
