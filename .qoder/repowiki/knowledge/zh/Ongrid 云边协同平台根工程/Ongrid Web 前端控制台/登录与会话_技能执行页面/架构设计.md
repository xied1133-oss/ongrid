本模块由三个独立的 React 页面组件构成，均位于 `web/src/pages` 下，作为路由级入口：
- `Login.tsx`：表单页，调用 `@/api/auth.login` 获取 access/refresh token，通过 Zustand store `@/store/auth.setSession` 写入会话并导航到根路径；错误统一用 `@/api/client.ApiError` 区分 401。
- `ChatThread.tsx`：核心聊天页，使用 `useParams` 读取 `sessionId`，通过 `@/api/chat.streamMessage` 的 SSE 回调（onAssistant/onToolStart/onToolEnd/onApprovalPending/onDone）增量更新本地 `messages` 状态，并通过 `@/api/chat.getMessages` + `listApprovals` 每 5 秒轮询以与 IM 桥（飞书/钉钉）共享会话；模型选择来自 `@/store/modelSelection`，权限控制来自 `@/store/me.usePermissions`，会话元数据来自 `@/store/chatSessions`。
- `SkillRun.tsx`：按 skill key 渲染动态参数表单，调用 `@/api/skills.executeSkill` 执行并维护最近 3 条历史记录；根据 skill 的 class（dangerous/mutating/inventory_only）和 scope（manager）切换 UI 与执行目标（云端 vs edge）。
依赖方向单向向外：页面 → `@/api/*` 客户端、Zustand store、`@/components/*` 展示组件、`@/i18n/locale` 多语言；页面之间无相互引用，仅通过路由参数或全局 store 间接通信。
