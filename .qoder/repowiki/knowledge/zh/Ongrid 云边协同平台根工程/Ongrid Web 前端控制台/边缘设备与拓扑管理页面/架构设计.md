模块由四个独立的 React 页面组件构成，分别对应不同的路由视图：
- `Edges.tsx`：设备列表页，通过 `usePoll` 每 10 秒轮询 `listDevices` + `listEdges`，结合 K8s 附件与拓扑集群信息渲染表格，支持批量选择、整包升级、自定义升级、删除 Edge、网络发现（SNMP）等；通过 `react-router-dom` 的 `Link`/`useNavigate` 跳转到 `/edges/shell-sessions` 和设备详情页。
- `EdgeDetail.tsx`：设备详情页，根据路径前缀区分 `/devices/:id`（主路由，解析 host edge）和 `/edges/:id`（兼容旧书签），按 tab 切换 metrics/host/plugins/topology/meta；metrics 子页使用 recharts 展示 CPU/磁盘/网络 RX/TX 四组 PromQL 面板，并通过 `openMetricDrilldown` 打开 Grafana 钻取；网络设备（`os === 'network'`）走专用 `NetworkDevicePage`，支持 SNMP 轮询配置。
- `Topology.tsx`：拓扑管理页，分 graph/nodes/relation-types 三个 tab，节点列表支持类型 chip 过滤与搜索，右侧抽屉显示邻居关系；类型管理 tab 可注册/删除节点类型与关系类型，所有 CRUD 调用 `@/api/topology`。
- `DeviceShell.tsx`：WebSSH 终端页，通过 `probeShellPreflight` 预检 HTTP 状态后建立 WebSocket，使用 `@/components/XTerminal` 渲染 xterm，以二进制帧传输 stdout/stdin，JSON 控制帧处理 ready/auth_error/exit/resize；通过 `beforeunload` 发送 close 帧保证审计行关闭。

依赖方向单向向下：页面 → `@/api/*`（edges/devices/topology/webshell/version）→ 后端；UI 复用 `@/components/ui`、`@/components/Modal`、`@/components/StatusPill`、`@/lib/usePoll`、`@/i18n/locale` 等共享能力，不反向依赖其他页面。
