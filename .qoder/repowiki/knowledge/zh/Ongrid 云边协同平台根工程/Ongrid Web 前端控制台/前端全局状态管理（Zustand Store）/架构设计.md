模块按职责拆分为独立 store 文件，每个文件通过 `zustand/create` 导出一个 React Hook（如 `useAuth`、`useChatSessions`、`useUi`、`useModelSelection`、`useObservability`、`useIncidentBadge`），供页面与组件订阅。
- 持久化策略：需要跨刷新保留的状态（auth、ui、model-selection、observability）统一使用 `zustand/middleware` 的 `persist` + `createJSONStorage(() => localStorage)`，并通过命名空间 key（如 `ongrid.auth`、`ongrid.ui`、`ongrid.model-selection`、`ongrid.observability`）隔离；不需要持久化的状态（me、chat-sessions、incident-badge）仅内存维护。
- 数据获取模式：store 内部直接调用 `@/api/*` 模块发起请求（如 `listSessions`、`getMe`、`listIncidents`），并在 store action 中处理 loading/error 状态；对高频或共享数据采用单飞请求去重（`me.ts` 用 `inflight` Promise 防抖）和定时轮询（`incidentBadge.ts` 每 30s 拉取未确认告警）。
- 跨 store 依赖方向：`me.ts` 依赖 `auth.ts` 监听 token 变化自动清理缓存；`incidentBadge.ts` 也读取 `auth.ts` 的 token 决定是否继续轮询，形成单向依赖链，避免循环引用。
- 非 Zustand 的全局偏好：`mode.ts` 不依赖 Zustand，而是通过 `localStorage` + `matchMedia` + 自定义事件 `ongrid-theme-change` 驱动主题切换，并提供 `applyThemeOnBoot` 在首屏前同步 DOM class，保证无闪烁。
