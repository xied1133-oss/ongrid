以 `src/main.tsx` 为唯一入口，在首次渲染前恢复主题/模式并设置语言，随后用 react-router-dom 的 BrowserRouter 挂载 App 完成路由装配；各业务域（agents_skills、alerts_incidents_tasks、clusters_kubernetes、edges_topology、flows_marketplace、knowledge_reports、monitor_dashboard、observability_logs_traces、auth_and_chat、settings_admin）均遵循同一契约：通过 `src/api/*` 中按领域拆分的 HTTP 客户端调用后端，使用 `src/store/*` 中的 Zustand slice 读写跨组件状态，复用 `src/components/ui` 与 `src/lib` 提供的通用 UI 原语与工具函数；E2E 测试位于 `e2e/`，单元测试位于 `src/**/*.test.*`，由 Playwright 与 Vitest+MSW 分别驱动，构建产物由 `vite.config.ts` 输出到 `dist/` 供静态服务器托管。
