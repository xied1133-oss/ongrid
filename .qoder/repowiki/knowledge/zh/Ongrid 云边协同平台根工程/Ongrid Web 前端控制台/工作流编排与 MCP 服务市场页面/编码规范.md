- 所有用户可见字符串统一通过 `useI18n().tr(zh, en)` 包裹，保证中英文切换。
- 写操作前通过 `useAuth((s) => s.role)` 判断 `canWrite = role !== 'viewer'`（或 `isAdmin`）再渲染编辑/删除按钮。
- 异步副作用统一用 `useEffect` + `let alive = true` 守卫取消未卸载组件的请求，并在 `finally` 中清理定时器。
- 错误处理遵循 `catch (e) { setError(e instanceof Error ? e.message : String(e)) }` 的模式，将错误写入本地 state 后在 UI 中以红色边框区域展示。
- 列表页统一采用「搜索框 + 计数提示 + 空状态卡片」布局，搜索逻辑在前端按 name/description 模糊匹配。
- 节点/配置项通过数据驱动定义：`NODE_META`、`CONFIG_FIELDS`、`baseNodeTypesFrom` 等表把后端返回的 `NodeType`/`FlowToolMeta` 映射为 UI 控件，避免硬编码分支。
