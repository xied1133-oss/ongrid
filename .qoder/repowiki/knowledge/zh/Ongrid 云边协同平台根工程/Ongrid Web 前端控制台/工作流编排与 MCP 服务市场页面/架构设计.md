模块由三个并列的 React 页面组成，均通过 `react-router-dom` 路由挂载：
- `Flows.tsx`：工作流清单页，负责列出、搜索、分页、创建（支持 AI 生成或空白命名）、运行、启用/停用、删除，并通过 `useNavigate` 跳转到 `/workflows/:id`。
- `FlowEditor.tsx`：基于 `@xyflow/react` 的流程图画布，左侧为节点调色板（基础节点 + 动态工具目录），中间是 React Flow 画布（自定义 `FlowCanvasNode` 渲染带端口 Handle 的节点），右侧抽屉根据选中节点类型动态渲染配置表单；通过 `toCanvas`/`fromCanvas` 在 `FlowGraph` 与 Canvas Node/Edge 之间双向转换，使用 `listNodeTypes`/`listFlowTools`/`listAgents` 从后端拉取节点规格、工具元数据与可用 Agent 名称，并以内置 `NODE_META`/`CONFIG_FIELDS` 作为降级表；运行态通过 `runFlow` + `getFlowRun` 轮询（1.5s 间隔）刷新节点状态并高亮成功/失败。
- `Mcp.tsx`：MCP 服务器管理页，CRUD 外部 MCP server，支持测试连接、查看拉取的 tool 列表、选择 Secret 注入 Header 模板，并提供 trusted/enabled 开关；仅 admin 可编辑/删除。
依赖方向单向：页面 → `@/api/*`（flows/mcp/secrets/agents）→ 后端 REST；UI 复用 `@/components/ui`（PageHeader/Button/Card/Chip/EmptyState）、`@/components/Modal`、`@/i18n/locale` 的 `tr()` 做中英双语。权限通过 `useAuth` 的 `role` 字段控制写操作（viewer 只读）。
