模块按职责分层组织：`ui/` 是视觉统一的基础原子层（Button、Card、Chip、EmptyState、PageHeader、PaginationFooter、RoleSelect），通过 `ui/index.ts` 桶文件集中导出，避免页面散落 className；业务级通用组件（ChatInput、MessageBubble、Modal、Sidebar、Layout、CommandPalette、AgentSidePanel、StatusRow、PromQLPanel、ThinkingMarkdown 等）位于根目录，由 `Layout.tsx` 组合成带 react-router Outlet、全局快捷键（⌘K/⌘P）、命令面板和 Agent 侧边栏的页面外壳，并通过 Zustand store（`@/store/ui`、`@/store/incidentBadge`、`@/store/auth`、`@/store/me`）驱动状态；`icons/Provider.tsx` 集中实现各 LLM 厂商 SVG 徽标，并提供 `ProviderIcon` / `ModelIcon` 根据 provider id 或 model name 分派的品牌徽章选择器；`monitor/`、`topology/`、`marketplace/` 分别封装监控面板网格、基于 @xyflow/react + dagre 的拓扑图、能力清单摘要等场景组件。依赖方向单向向外：组件仅消费 `@/api/*`、`@/store/*`、`@/i18n/locale`、`@/lib/cn`，不反向被 API/store 依赖。
