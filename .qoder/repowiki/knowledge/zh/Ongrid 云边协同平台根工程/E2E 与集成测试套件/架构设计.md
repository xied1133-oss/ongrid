测试代码按运行粒度分为两层：`tests/e2e/` 为带 build tag `e2e` 的端到端测试，每个用例通过 `testenv.Start(t)` 在 Docker 中拉起一个共享的 `mysql:8.0` 容器、用 `os/exec` 构建并 spawn 真实的 `cmd/ongrid` 管理进程（监听随机端口并通过 `/healthz` 轮询就绪），同时启动内嵌的 `httptest.Server` 作为 FakeLLM、FakeSlack、FakeTelegram、FakeProm；`tests/integration/` 为轻量集成测试，使用内存 SQLite + GORM 直接串联 biz usecase（如 secret → approval → executor 执行链），不启动 HTTP 或外部服务。`main_test.go` 中的 `TestMain` 负责进程退出时调用 `TerminateSharedMySQL()` 回收 testcontainers 容器，避免泄漏。各测试文件以 `<area>_<short>_test.go` 命名，对应 `docs/test/e2e-catalog.md` 中的编号用例，通过 `testenv.DoJSON/Login` 等封装对 manager HTTP API 发起请求并断言 JSON 响应。
