- 每个业务域按 server/<domain>/http.go → service/<domain>/service.go → biz/<domain>/usecase.go → data/<domain>/store/repo.go 的镜像目录组织，依赖方向单向向下。
- HTTP Handler 通过构造函数注入 Service 接口（如 IncidentService、ChannelService），可选能力（如 InvestigationReader）通过 WithXxx 方法按需装配，支持二进制裁剪。
- Service 层承担 DTO↔Model 转换与输入校验，将业务错误包装为 `internal/pkg/errs` 中的 ErrInvalid/ErrNotFound/ErrUnauthorized 等标准错误。
- Store 层统一使用 `gorm.DB.WithContext(ctx)` 构造查询，并将 gorm.ErrRecordNotFound 转换为 errs.ErrNotFound。
- 变更型 HTTP 端点在执行业务操作后通过 `server/middleware` 的 SetAuditEvent 记录审计日志，资源标识由 ResourceID/ResourceName/Payload 描述。
- AIOPS 工具通过 `tools/basetool` 基类与 `tools/decorators` 装饰器链（审计、限流、超时、人工审批、租户绑定）组合，新工具只需实现 basetool 接口即可接入。
