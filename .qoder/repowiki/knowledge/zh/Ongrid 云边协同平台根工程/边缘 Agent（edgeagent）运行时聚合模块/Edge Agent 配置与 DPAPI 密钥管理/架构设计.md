模块由两个子包组成，依赖方向单向：config → dpapi。
- `dpapi` 包通过 Go build tag (`//go:build windows` / `!windows`) 提供跨平台接口：`Protect`/`Unprotect` 在 Windows 上调用 `golang.org/x/sys/windows.CryptProtectData/CryptUnprotectData`，使用 `CRYPTPROTECT_LOCAL_MACHINE` scope 将密文绑定到本机 System 身份；非 Windows 平台返回 `ErrUnsupportedPlatform`，使上层可在 Linux 等环境编译引用。
- `config` 包暴露高层 API：`LoadSecrets(path)` 负责读取 `secrets.enc` 并通过 `dpapi.Unprotect` 解密出 broker token；`CheckTokenRotation(tokenAge, rotationDays)` 结合 `defaultRotationDays=90`、钳制范围 `[30, 365]` 判断是否需要轮转。
- 错误处理采用 `fmt.Errorf(... %w)` 包装底层错误，调用方需回退到 `ONGRID_EDGE_SECRET_KEY` 环境变量以兼容旧部署。
