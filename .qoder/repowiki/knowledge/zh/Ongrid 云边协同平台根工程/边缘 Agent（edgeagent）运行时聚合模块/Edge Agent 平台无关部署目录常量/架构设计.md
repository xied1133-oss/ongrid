包以 Go build tag 实现平台隔离：`edgedirs_linux.go` 通过 `//go:build linux` 提供 FHS 风格路径（/usr/local/bin、/var/lib/ongrid-edge），`edgedirs_windows.go` 通过 `//go:build windows` 提供 Windows Service 标准路径（Program Files / ProgramData）。两个平台文件均导出相同的常量集合 BinDir、DataDir、PluginWorkDir、StageDir，使上层 worker 与 supervisor 无需感知平台差异即可访问统一路径；Windows 侧额外导出 HealthFile（IPC health.json）与 WorkerBinary 常量。包本身不暴露函数，仅作为跨 binary 共享的 source of truth。
