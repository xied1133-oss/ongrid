- 每个 Pusher 暴露 `Run(ctx)` 循环，内部用 `time.Ticker` 周期调度并通过 `edgeID()` 惰性获取边节点 ID，未就绪时阻塞等待。
- 配置项在构造函数中集中做默认值填充与边界校验（区间、URL 合法性、必填字段），失败返回带前缀的错误信息。
- 对 kube-apiserver 的 HTTP 请求统一封装在 `apiClient.doRaw/get/getRaw` 中，集中处理 Authorization Bearer、Accept 头、403/404/非 2xx 状态码并转换为哨兵错误。
- 资源列表通过泛型 `listAllK8sItems[T]` 配合 `k8sListPage` 结构体实现分页拉取，并以 `limit=500` 控制页大小。
- watch 循环采用指数退避重试（上限 30s），并根据 `errResourceExpired` 触发 full resync 而非增量推送。
- action 路由采用 `normalizeK8sAction` 字符串归一化 + switch 分发到专用方法，每个方法负责构造对应 PATCH/DELETE/EVICT body 并复用 `addResourceVersionPrecondition` 与 `withDryRun`。
