本模块以 biz/collector 的 Agent 主循环为运行核心：定时触发指标采集（内置 gopsutil 采集器 + HTTP scrape），并通过 k8s_data_plane 将清单、指标与动作上报至 Kubernetes；同时由 plugins/supervisor 编排 metrics/logs/traces 等子进程插件，复用同一采集-上报通道。所有外部调用入口统一收敛在 streamrouter/router.go 的隧道流路由与 skill/dispatcher.go 的技能注册表中，bash/host_files/operator/restart_service/service/webshell 等 handler 仅作为协议适配层，实际逻辑委托给 cmdpolicy 沙箱、host_file_ops、packet_capture、install_service 等平台相关实现。跨平台差异通过 edgedirs（部署路径）、dpapi/config（密钥）、install/*_windows.go、packetcapture/*_linux.go 等 build tag 文件隔离，model/ 提供边端向云端上报的统一数据结构。
