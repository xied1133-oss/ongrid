模块由两个并列子包组成：
- `install`：通过 `interfaces.go` 定义三个正交接口 `SecretStore`（DPAPI 加密凭证 secrets.enc）、`ServiceController`（sc.exe 包装的 Windows Service 生命周期）、`EnvWriter`（注册表 Environment REG_MULTI_SZ），实现按平台拆分——`*_windows.go` 提供真实实现（`service_windows.go`、`acl_windows.go`、`secrets_windows.go`、`env_windows.go`），`install_other.go` 在非 Windows 构建中返回 `ErrUnsupportedPlatform` stub，使 manager（Linux）可安全引用该包而不编译失败。
- `restart_service`：通过 `tunnel.Client.RegisterHandler` 注册 `MethodRestartService` 处理器，使用 `SandboxConfig`（含 `AllowedUnits` 白名单与 `Mocked` 开关）做 defense-in-depth 校验；当前以 mock 模式返回成功，预留后续真实 `systemctl` shell-out。
依赖方向单向：上层 orchestrator 组合三个接口完成安装编排，`restart_service` 仅依赖 `internal/pkg/tunnel` 暴露 handler，不反向依赖 `install`。
