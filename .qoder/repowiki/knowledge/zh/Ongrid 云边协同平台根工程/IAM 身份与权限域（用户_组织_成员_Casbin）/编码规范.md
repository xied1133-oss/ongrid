- HTTP handler 统一通过 `decode`/`parseID`/`writeJSON`/`writeErr` 等局部辅助函数处理请求体、URL 参数与响应，错误一律包装为 `errs.*` 并映射为 HTTP 状态码。
- 需要管理员权限的路由在 handler 开头调用 `requireAdmin`，从 `tenantctx` 取出角色并与 `model.RoleAdmin` 比较后返回 ErrUnauthorized/ErrForbidden。
- 可选的后端能力（org/membership/authz）通过 Service 上的 `SetXxx` 延迟注入，handler 中以 nil 检查返回 `errs.ErrNotWiredYet`，使旧部署保持绿色。
- biz 层的 Repo 接口在 data 子包中以 `var _ biz.Repo = (*Repo)(nil)` 进行编译期契约校验，确保实现不漂移。
- 所有数据库写操作在影响行数为 0 时统一返回 `errs.ErrNotFound`，读操作将 gorm.ErrRecordNotFound 转换为 errs.ErrNotFound，向上层暴露一致的错误语义。
- 敏感字段（PassHash）在 Usecase 返回前显式清空，避免通过 API 泄露密码哈希。
