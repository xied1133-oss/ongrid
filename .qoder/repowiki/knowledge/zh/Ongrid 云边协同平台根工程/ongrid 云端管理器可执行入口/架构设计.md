本模块是 Go `main` 包，作为 ongrid 云端管理器的单一可执行入口（`cmd/ongrid/main.go`），承担应用装配职责：
- 启动阶段按固定顺序完成：读取 `config.Load()` → 初始化 slog + OpenTelemetry tracing → 打开 GORM DB 并串行调用各 data store 的 `Migrate` 函数执行 AutoMigrate → 构建加密凭据库 secretbox。
- 业务域装配：先组装 IAM（用户/组织/成员/casbin 授权），再组装 Manager 各子域（edge/device/k8s/logs/metric/alert/topology/aiops/prometheus/grafana/webshell/skill/marketplace/secret/setting/report/flow/packetcapture/monitor/integration 等）的 biz/service/server 三层，并通过 Usecase 之间的 setter 注入协作关系（如 topologyUC 作为 node mirror 注入到 edge/device/k8s UC）。
- HTTP 路由通过 go-chi/v5 注册，所有 mutating 路由统一经 `authzmw.New(authzEnf)` casbin 中间件；metrics 暴露 Prometheus `/metrics`，tracing 上报至 Tempo OTLP。
- 与上游 `frontier` broker 通过 `manager/service/frontierbound` 建立长连接，注册生命周期回调（GetEdgeID/EdgeOnline/EdgeOffline）和反向调用处理器（register_edge/heartbeat/push_host_metrics），实现云→边的双向通信。
- 启动后执行多项 boot backfill：修复 stale online edge、失败 orphaned investigation、reconcile deleted topology/orphan devices 等数据一致性任务。
- 同目录下的 `_test.go` 文件均为该入口的集成测试，覆盖 coordinator_tools、k8s telemetry target、logs connection inventory、mutating proposal sink、LLM default、kernel 等场景。
