- 每个 skill 实现一个结构体并实现 Executor 接口（Metadata + Execute），在包 init() 中通过 skill.Register 注册到全局 Registry。
- 技能元数据使用 Metadata 声明 Key/Name/Description/Class/Scope/Params，并由 Validate 在注册时校验，Key 必须为 lower_snake 且仅含 a-z0-9_。
- 权限分类统一使用 Class 常量（ClassSafe/ClassMutating/ClassDangerous），未显式设置时默认降级为 safe。
- 运行范围通过 Scope 区分：设备侧能力用 ScopeHost，管理器侧能力（含所有 SubprocessSkill）强制为 ScopeManager。
- 外部子进程技能的入口路径经 Loader 解析后必须落在配置的 allowlist 根目录下，并通过 EvalSymlinks 检测 symlink 逃逸。
- 子进程环境采用 deny-by-default 策略，仅白名单 EnvAllow 中的环境变量被显式注入，未包含 PATH 时子进程无 PATH。
