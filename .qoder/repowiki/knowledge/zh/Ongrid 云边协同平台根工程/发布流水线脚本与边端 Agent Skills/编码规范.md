- 所有 bash 脚本以 `#!/usr/bin/env bash` 开头并启用 `set -euo pipefail`，通过显式参数校验与 `command -v` 检查外部依赖后再继续执行。
- 对外部资源访问采用重试模式：使用 `attempts`/`retry_delay` 环境变量控制循环次数与退避间隔，错误输出到 stderr 并返回非零退出码。
- 临时文件统一通过 `mktemp -d` 创建并由 `trap 'rm -rf ...' EXIT` 清理，避免并发场景下的状态残留。
- CNB 相关脚本通过 `Accept: application/vnd.cnb.api+json` 头调用 REST API，并使用 `jq` 对响应进行结构化校验后再消费。
- Skills 以目录为单位组织，每个 SKILL.md 使用 YAML front matter 声明 `name`、`metadata.requires.bins`、`edge_capabilities`、`activation` 等元数据，正文用 `[能力: xxx]` 标题描述调用规则与白名单。
- 测试脚本通过断言 Makefile/GitHub Actions workflow 中的关键字符串（如 Make target 名、平台矩阵、digest 路径）来保证发布流水线配置的一致性。
