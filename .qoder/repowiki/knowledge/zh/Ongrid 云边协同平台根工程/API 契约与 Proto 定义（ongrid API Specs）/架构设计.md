模块以 `buf.yaml` + `buf.gen.yaml` 为构建入口，使用 buf v2 对 `api/` 根目录进行 lint（STANDARD）与 breaking 检测（FILE），并通过 go/grpc 插件生成到 `api/gen/<service>/v1/`（source_relative 路径，`.gitignore` 忽略）。按业务域分层组织 proto：
- `iam/v1/iam.proto`：定义 `IamService`，负责登录、JWT 签发、Org/User/Membership 管理。
- `manager/*/{v1}/*.proto`：按子域划分（edge、k8s、metric、aiops、alert、notification、packetcapture、setting、logs），每个 `.proto` 对应一个 gRPC service，由 chi 手写 REST 路由调用对应 Go handler。
- `tunnel/v1/tunnel.proto`：不声明 gRPC service，仅定义通过 geminio 隧道传输的请求/响应消息体（MVP 走 JSON，Phase 2 可切二进制），与 manager 各子域解耦，刻意复制 HostInfo 等类型以保持自包含。
依赖方向单向：tunnel → 无 manager 依赖；manager 各子域互不引用；所有 org_id/user_id 等上下文信息约定来自 JWT claims / URL path，不在请求体中暴露。
