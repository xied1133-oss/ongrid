### ongrid
- 定义：项目名，开源 AIOps 平台（AGPLv3），提供告警自动调查、拓扑影响面 RCA、远程执行、工作流编排、知识库与代码 RAG、专家 Agent、Kubernetes 生命周期管理、网络设备 SNMP 管理等能力。当前版本 v0.14.0，仓库地址 github.com/ongridio/ongrid。
- 别名：Ongrid、ONGRID

### Manager
- 定义：Ongrid 管理中心进程（cmd/ongrid），承载 Web UI、API、业务逻辑（internal/manager/biz）、鉴权、Agent 调度等，以容器形式通过 docker-compose 启动，对外暴露 HTTPS 8443 端口。
- 别名：管理中心、云端

### Edge / Edge Agent
- 定义：部署在被管主机上的 agent 进程（cmd/ongrid-edge），作为 systemd 服务运行，负责 bash 沙箱、指标采集、抓包、webshell、K8s operator 等，通过反向隧道主动外联云端 40012 端口，无需对主机开放入站端口。
- 别名：边缘代理、被管主机 agent

### install.sh
- 定义：Ongrid 发布包自带的一键安装脚本，负责环境自检、创建 /opt/ongrid、下载 Edge 制品、生成自签 TLS 证书、生成 .env（空密码自动随机填充）、拉取镜像、启动全栈、轮询 healthz 并打印管理员初始密码。支持 --no-seed、--force、--profile monitoring 参数。
- 别名：安装脚本

### upgrade.sh
- 定义：升级脚本，预取新版本 Edge 制品并渲染新 Compose 拉镜像，不覆盖 .env 和 certs/，仅更新 ONGRID_VERSION 并补齐缺省项；升级失败保留旧栈与旧 /edge 目录，支持 --repair-permissions 修复权限。
- 别名：升级脚本

### uninstall.sh
- 定义：卸载脚本，默认只停止容器保留数据卷和 /opt/ongrid；加 --purge --yes 则彻底删除 MySQL 数据卷、/opt/ongrid 和 ongrid 镜像。
- 别名：卸载脚本

### .env
- 定义：Ongrid 安装后生成的配置文件（/opt/ongrid/.env，权限 600），集中存放 MYSQL_ROOT_PASSWORD、MYSQL_PASSWORD、JWT_SECRET、ADMIN_EMAIL/PASSWORD、OPENAI_*、HTTP_PORT、TUNNEL_PORT 等全部运行时配置；install.sh 首次安装时对空字段自动生成随机值，升级不覆盖已有值。
- 别名：环境变量文件、配置文件

### Edge 隧道
- 定义：Edge Agent 主动外联云端的反向 TCP 通道，默认端口 40012，用于承载浏览器 SSH、远程执行、抓包、指标上报等所有管理流量，使被管主机无需开放任何入站端口。
- 别名：反向隧道、40012 端口

### 安全组
- 定义：阿里云 ECS 的网络访问控制策略，需在控制台放行 Ongrid 所需端口：8443/tcp（Web UI/API/Grafana）、8800/tcp（HTTP→HTTPS 跳转，可选）、40012/tcp（Edge 隧道）、22/tcp（SSH，建议限制来源 IP）。系统防火墙（firewalld/ufw）是第二层，需同步放行。
- 别名：ECS 安全组、防火墙

### ICP 备案
- 定义：中国大陆域名 ICP 备案要求。使用 IP:8443 非标准端口直连不需要备案；若绑定域名走 80/443 标准端口，则域名必须先完成备案。
- 别名：域名备案

### CNB
- 定义：Cloud Native Buildpacks 生态中的制品库平台（cnb.cool），Ongrid 的容器镜像、Edge 安装制品、公共依赖 Release 均从此处分发；国内 ECS 可直接访问无障碍。
- 别名：docker.cnb.cool、CNB 制品库

### Edge 制品
- 定义：Edge Agent 的二进制及其依赖，默认从 cnb.cool 的 Release 下载，包含当前 Ongrid 版本的自研 ongrid-edge 和不可变的 edge-deps-* 公共组件；可通过 ONGRID_EDGE_ARTIFACT_BASE_URL 覆盖下载源，或通过 ONGRID_BUNDLE_EDGE_ASSETS=1 make package 打包进离线发布包。
- 别名：edge artifacts、Edge 安装制品
